# NullMotion Helper Marketplace

Unofficial helper for https://github.com/blixvip/NullMotion.

Marketplace URL:
https://github.com/senjaliyaprince03-rgb/nullmotion-marketplace

Install nullmotion-helper, then run /nullmotion-helper:setup
in a local Claude Code session.

This plugin supplies a setup workflow. It does not bundle NullMotion,
automatically install Node.js, or embed the application inside Claude.
